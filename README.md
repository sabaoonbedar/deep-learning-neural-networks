# Deep Learning Neural Networks

This project is an end-to-end implementation of **artificial neural networks (ANNs)** built from scratch in **Python**, designed to explore and understand the core concepts of deep learning without relying on high-level libraries like TensorFlow or PyTorch.

---

## Overview

The project implements a **custom neural network framework** with flexible layer structures, activation functions, and training algorithms. It has been tested on benchmark datasets such as:

- **Iris Dataset (UCI ML Repository)**  
  Achieved up to **100% accuracy** across multiple training runs.

- **UCI ML Handwritten Digits Dataset**  
  Achieved up to **95.15% accuracy** in classification tasks.

These results demonstrate the ability of the implemented neural network to generalize across both small-scale structured datasets and larger image-based datasets.

---

##  Features

- Fully **custom-built neural network architecture** (no TensorFlow / PyTorch)
- **Layer-based design** for modularity and experimentation  
  (see the `layers/` folder for implementation)
- Support for multiple **activation functions** and **loss metrics**
- Gradient-based **backpropagation** and **weight updates**
- Training and evaluation on **multiple datasets**
- **Extensive performance logging** and result tracking
- Written for **educational clarity and experimentation**
